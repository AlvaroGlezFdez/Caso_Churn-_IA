# Data

This project uses the **academic case dataset** provided for the course (car-dealership
sales, demographics, vehicle, maintenance and complaint history). The raw data files are
**not included** in this repository (size, and to keep customer-like records out of a
public repo).

The processed feature matrix (`X_model_ready.csv`) is regenerable from
`notebooks/FEATURE_ENGENEERING_FINAL.ipynb`. The dataset schema is documented in
[`../docs/metadata.md`](../docs/metadata.md).
